قائمة سطح المكتب — طريقة التثبيت (الصور في install-steps.png)

1) فك الضغط: كليك يمين ← استخراج الكل.
2) شغّل DesktopMenu.exe
   إذا ظهرت رسالة "Windows protected your PC": More info ← Run anyway.
3) اختر مكان الأيقونة (تقدر تختار أكثر من مكان) واضغط تثبيت:
   • قائمة الأيقونات المخفية (تحت السهم ^)
   • بجانب الساعة
   • قائمة ابدأ — ومنها لشريط المهام لاحقاً: كليك يمين ← تثبيت في شريط المهام
4) خلاص. يشتغل تلقائياً مع تشغيل الجهاز، وتقدر تحذف الملف اللي نزّلته.


Desktop Menu — How to install (pictures in install-steps.png)

1) Unzip: right-click > Extract All.
2) Run DesktopMenu.exe
   If "Windows protected your PC" appears: More info > Run anyway.
3) Tick where the icon goes (one or more) and press تثبيت (Install):
   • Hidden icons (under the ^ arrow)
   • Next to the clock
   • Start menu — pin it to the taskbar later: right-click > Pin to taskbar
4) Done. It starts with Windows; you can delete the downloaded file.
